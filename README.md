# Telco Customer Churn: EDA & Pre-processing

**Andre Ellis | ITAI1371 | Solo project**

Original dataset (Kaggle): https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## How to run
1. Put the Kaggle download (`archive.zip`, or the CSV) in the `data/` folder. Do not edit it.
2. `pip install -r requirements.txt`
4. Clean train/test CSVs are written to `output/`.

## Contents
- `Project_Proposal_Telco_Churn.pdf`: one-page dataset description and proposal
- `dataset_url.txt`: URL of the original dataset
- `output/telco_churn_train_clean.csv`, `output/telco_churn_test_clean.csv`: final clean data
- `Reflection_Journal.md`, `Contribution_Journal.md`: journals
